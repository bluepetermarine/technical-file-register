Notes on Applicability

  1. This register lists only the drawing-type and calculation-type deliverables required for the Module B / G technical file under the Recreational Craft Directive 2013/53/EU. It is not the full technical file; test reports, descriptions, part lists, supplier certificates and the Owner's Manual are held separately.
  2. Items apply as far as applicable and appropriate to the actual craft. Final applicability is confirmed once the systems, design category and hull length are established. Rows that do not apply to the craft should be marked N/A rather than deleted.
  3. All installation schemes and drawings must be numbered and carry revision dates where changes are made.
  4. The engine room net volume figure (C-06 and C-07) is a single physical value serving two clauses — fixed fire-fighting provision and ventilation. Calculate once and reference it in both places.
  5. Structure (C-04): where rules other than ISO 12215 have been applied to achieve structural integrity, agree the approach with the Notified Body up-front.
  6. Multihull inversion items (D-18, C-05) apply only to habitable multihull craft susceptible of inversion. Confirm applicability for the specific model before requesting these from the yard.
  7. The date and signature on the certification application set the reference date for the standards applicable to the assessment.
